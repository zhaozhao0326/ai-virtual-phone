- 第 317-330 行 `parseMixMaterialsFromJson`：检测到 `chara_card` spec 也抛错

**要改的地方**（只需改 `lib/mixology/transfer.ts` 一个文件）：

1. **新增 SillyTavern → MixCharacterCard 映射函数**，字段对照表：

| 酒馆 Character Card V2 (data 字段) | → 独家特调 MixCharacterCard | 备注 |
|------|------|------|
| `name` | `charName` | 角色名（必填） |

| `personality` | `personality` | 性格 |
| `scenario` | `plot` | 当前剧情 |
| `first_mes` | `openings[0]` | 第一条开场白 |
| `alternate_greetings[]` | `openings[1...]` | 备选开场白 |
| `mes_example` | `examples[]` | 需解析 `<START>` 分隔 + `{{user}}:`/`{{char}}:` 标记 |
| `tags[]` | `tags` | 标签 |
| `creator` | `author` | 作者署名 |
| `character_book` | → 拼成 `base`（基底）材料 | 世界书 entries 拼成文本 |
| `system_prompt` | → 单独 `base` 材料 | 如有 |
| `post_history_instructions` | → 单独 `strength` 材料 | 如有 |
| `creator_notes` | `hook` | 一句话介绍 |

3. **修改 `parseMixMaterialsFromJson`**：检测到 `chara_card` spec 时不再抛错，而是调映射函数
4. **`mes_example` 解析逻辑**：酒馆格式示例：
   ```
   <START>

   ```
   需要按 `<START>` 分段，每段按 `{{user}}:` / `{{char}}:` 前缀拆成 `{ role: "user"|"char", text }`

   ```json

     "name": "世界书名",

       { "keys": ["关键词1","关键词2"], "content": "条目内容", "enabled": true, "position": "before_char" }
     ]
   }
   ```
   把所有 enabled 条目拼成文本：`[关键词] 内容`，作为 `base`（基底）材料入库
6. **封面图**：PNG 本身就是图片，可以直接当 `MixCharacterCard.cover`

## 五、已知架构知识点

### 5.1 群管理动作
- 群聊内走 `applyAIGroupAdminAction`
- 1:1 私聊走 `applyAIOneToOneGroupAdminAction`（找角色作为 owner/admin 所在的群执行）
- 标签链路：模型输出 `[A动作]` → `rich-message-parser` 解析 → chat-room 派发执行
- 管道符格式：`[A 设置群公告|内容:xxx]`（参考建群格式 `[A 建了个群|群名:XX|成员:XX]`）

### 5.2 角色卡存储
- 本 App 自己的角色卡：`lib/character-storage.ts`
- 独家特调的角色卡：`lib/mixology/types.ts` 的 `MixCharacterCard`（完全不同的类型系统）
- 两者不互通：角色卡 App 导入的酒馆 PNG 不会出现在独家特调里，反之亦然

### 5.3 世界书
- 全局世界书：`lib/settings-storage.ts` 的 `WorldBookConfig`
- 酒馆 PNG 里内嵌的世界书：`character_book` 字段
- 独家特调没有"世界书"概念，用 `base`（基底）材料替代

### 5.4 WorkBuddy 沙箱限制
- 批量删除文件（超 50 个）会被 genie-safe-delete 拦截
- `next build` / `next dev` / `next start` 清理 `.next` 目录会撞墙
- 绕法：`mv .next .next_old_xxx`（重命名绕开删除）

### 5.5 验收脚本
- `verify-group-create.mjs`：52 项静态断言，群管理改动后必跑
